# AI 中級名詞消消樂｜iPAS 實戰版

一個針對 iPAS AI 應用規劃師中級常見技術名詞設計的配對複習小遊戲。

## 第一版功能

- 8 大主題分類
- 中英文名詞 × 中文概念配對
- 每回合隨機抽題
- Combo 連擊與分數
- 錯題提示與觀念解釋
- 本機保存最高分、累積答題與錯題紀錄
- 可依分類練習或全範圍混合
- 純 HTML / CSS / JavaScript，可直接部署到 GitHub Pages

## 題庫分類

1. AI / 機器學習核心
2. 統計與模型評估
3. 生成式 AI / NLP
4. 資料工程 / 大數據
5. API / 微服務
6. MLOps / 部署監控
7. 雲端 / 基礎架構
8. AI 治理 / 專案管理

## 執行

直接開啟 `index.html`，或使用 GitHub Pages 發佈。

> 題庫位於 `data.js`，後續可持續新增與調整中級考點。
