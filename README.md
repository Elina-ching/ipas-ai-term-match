# AI 群島冒險｜iPAS 學習派對

保留貨運快手、翻牌對對碰、名詞高射炮，新增初級獨立題庫、冒險地圖與中級 Python 研究島。

- 初級 36 個知識點；中級 136 個，皆保留既有題庫。部分知識點附官方科目與勘誤頁碼，見 `learning.html`。
- Python 18 題：輸出雷達、程式修復、流程拼圖。自編讀碼練習，不執行任意 Python。
- 初／中級本機紀錄分開；舊版紀錄在中級繼續讀取。
- 貨運預設學習模式，每題停留看解釋；可取消切回節奏挑戰。
- 錯題再練、逐題詳解、Python 每局正確率、減少動畫、鍵盤可操作。
- 隨機匿名身分，世界榜依每個等級答對的不同知識點計星；同題不重複累積。
- 答對的知識點先寫入本機佇列再上傳：斷線或尚未加入世界榜時都不會遺失，連線恢復或加入後自動補送；已計星的不再重送，不浪費免費寫入額度。
- 後端有平台限流（一般 API 每分鐘 60 次、建立身分每分鐘 3 次）與 2,000 個匿名身分上限，額滿時明確拒絕而非默默失敗。
- 靜態資源附 CSP 等資安標頭，設定寫在 `_headers`，由 `build.mjs` 產生給 Worker 套用。
- 世界榜為休閒性學習紀錄。題庫與答案公開，不能防止使用者自行呼叫 API 回報已知答案，不適合獎金或正式競賽。

## 本機或 GitHub Pages

根目錄 `index.html` 為入口，無 npm 套件、付費 API、外部字型或追蹤碼。GitHub Pages 可直接服務所有遊戲；未設定 Worker 後端時，世界榜會明確顯示尚未啟用，不顯示假排名。

## 免費匿名世界榜部署

需要擁有者的 Cloudflare Free 帳戶和部署授權。此提交未啟用任何付費服務。不能在缺少帳戶連線時代為建立後端。

1. 在 Cloudflare Free 帳戶建立 D1 資料庫 `ipas-adventure`，將資料庫 ID 填入 `wrangler.jsonc`。
2. 本機執行 `node build.mjs`，生成 `public/` 與後端答案白名單。
3. 用免費 Wrangler CLI 執行 `npx wrangler d1 execute ipas-adventure --remote --file=server/schema.sql`。
4. 執行 `npx wrangler deploy`。遊戲與 API 同一個 Worker 網址，無須 CORS 或公開金鑰。
5. 在兩個獨立瀏覽器加入，答對不同知識點、更新榜單，再驗證刪除身分。

**目前狀態：** 已部署於擁有者的 Cloudflare Free 帳戶，`wrangler.jsonc` 內的 `database_id` 為實際資料庫編號（資源識別碼，非金鑰，無帳戶授權無法存取）。要部署到別的帳戶，請改成自己的 D1 ID 並自行建立兩個限流器綁定。GitHub Pages 單獨無法提供多人共用資料庫；完整多人版應分享 Worker 網址。

## 隱私

不要求姓名、Email、電話、自由文字暱稱或社群登入。伺服器只保存隨機 ID、雜湊登入憑證、系統隨機代號、答對知識點，以及最後一次動作的時間戳（`activity` 表）。原始憑證只在加入時回傳並存在該瀏覽器。使用者可刪除自己的雲端紀錄；刪除操作須出示憑證，刪除會連帶清除該身分的所有知識點、彙總與時間戳。清除瀏覽器會失去登入憑證，無法恢復身分，因此清除前請先刪除雲端身分。主機供應商仍可能處理必要連線資訊，不能宣稱完全不存在 IP 等個人資料處理。限流器會以連線 IP 作為限流鍵短暫處理該值，應用資料庫不保存 IP，Worker observability 預設關閉。

## 驗證

```
npm install
node build.mjs
node --test tests.mjs server-tests.mjs
node smoke.mjs https://你的-worker-網址
```

`tests.mjs` 檢查題庫完整性、答案白名單與靜態頁面連結；`server-tests.mjs` 以記憶體 SQLite 假造 D1，涵蓋雙身分隔離、併發去重、跨等級拒絕、限流、資料庫失效與資安標頭。`smoke.mjs` 對已部署網址做雲端驗收，結束時會刪除自己建立的測試身分。

2026-09-06 實測紀錄：12 項 Node 測試通過；雲端驗收對正式網址通過且測試資料已清除；瀏覽器實測首頁、三款遊戲與 Python 島在正式站無 console 錯誤，資安標頭確認生效；離線佇列以五個情境驗證（加入前暫存、斷線保留、連線恢復補送、已計星重複作答不呼叫 API、刪除身分後同步狀態清空）。
